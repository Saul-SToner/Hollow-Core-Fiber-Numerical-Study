# 适用范围与研究边界

## 软件

- 已验证环境为Windows / Python3.13.1；其他Python版本、Linux及macOS待测试。安装元数据仅允许3.13系列，不意味着该系列所有补丁版均已实测。
- M1是受限表达式的数值求值与SI换算，不是通用量纲推理、模型几何验证或经过安全认证的执行沙箱。
- M2使用峰值相量与显式坐标/权重；有限轮廓有符号通量不是独立出射通道，正观察内积不等于能量/磁通度量。只接受人工fixture，不导入真实研究场。
- Fourier积分是带权矩，不是任意非正交网格的逆问题；有限角带不能普遍保证场重构/Parseval闭合。演示只用可解析的有限Fourier和验证算术。
- M3仅启动固定dummy，不是任意命令runner、集群调度或资源监控。进程完成与算术验收分开；hash不是数字签名，原子文件替换不保证掉电恢复。

## 人工演示与真实研究

全部示例标记ALGORITHMIC_FIXTURE_NOT_COMSOL，不保证满足Maxwell/curl/出射条件。演示图是单位为任意单位的人工函数，不是COMSOL场、模态、本征谱、辐射或损耗数据。软件测试通过不证明物理模型精度、网格/PML收敛或性能优势。

原研究中的B/R独立预测优势尚未得到确认，NO_FORECAST、目标验证未开始、部分模态身份失败及机制UNRESOLVED均保留。本软件不恢复这些资格，也不宣称发现Fano、BIC或异常点。已见数据的场拟合不能当作未见目标预测。

# Optical Simulation Toolkit

**基于 Python 的光学仿真数据处理与科学计算工具包**

本项目源于反谐振空芯光纤（Anti-Resonant Hollow-Core Fiber）的电磁仿真研究，围绕科研计算中经常遇到的三个问题，开发了一套独立的 Python 工具：

- **参数管理：** 如何保证输入参数正确，避免单位、表达式或参数来源错误？
- **数值计算：** 如何正确处理复数电磁场数据，并验证计算结果的数值一致性？
- **任务追溯：** 如何记录程序的运行状态，并在出现异常时保留可以检查的证据？

项目分为三个模块，分别负责参数校验、复场数值处理和计算任务追溯。

工具包**不依赖 COMSOL**，可以独立安装与运行，并配备命令行接口（CLI）、自动化测试和可复现的人工数值示例。

> 本仓库展示的是从光学研究中提炼的软件工程与科学计算能力，不是完整的电磁场求解器，也不代表已验证的 B/R 理论或实际光纤损耗预测。

## 1. 项目背景：为什么要开发这些工具？

在实际光学仿真研究中，获得计算结果只是工作的一部分。

以空芯光纤的电磁模态分析为例，一项完整的计算可能涉及：

1. 从论文或设计方案中整理几何参数。
2. 将不同单位的参数转换为统一格式。
3. 配置电磁场计算模型并执行求解。
4. 读取复杂的电场、磁场和模态数据。
5. 利用 Python 进行功率、相位、频谱等数值分析。
6. 验证数据处理结果，并记录异常与计算历史。

其中很多错误并不是由复杂的物理理论引起的，而可能来自一些基础问题。

例如：

- 将微米误作为米输入，使几何尺寸出现数量级错误。
- 参数依赖关系写错，导致计算使用了不符合预期的输入。
- 在复电磁场积分时忽略法向方向，使功率流符号错误。
- 把两个复场的相位差误认为物理场形状发生变化。
- 某次计算中途失败，却仍将残留文件当作成功结果使用。
- 多次实验产生大量输出文件，无法准确确认结果对应哪一组输入。

这些问题不一定需要更复杂的物理模型来解决，却需要规范的数据处理和软件工程方法。

因此，本项目将相关需求提炼成三个能够独立测试的 Python 模块。

## 3. 核心模块

### M1：参数配置与输入校验

**解决的问题：如何在计算开始之前发现不合理的输入？**

光学仿真经常涉及大量参数，例如光纤尺寸、波长、角度和参数间的依赖关系。如果直接使用未经检查的输入，可能导致后续计算全部无效。

本模块使用 Python 与 Pydantic 建立参数约束，能够：

- 验证参数是否具有必要的来源信息。
- 检查参数名称、数值类型及依赖关系。
- 在受限表达式范围内计算派生参数。
- 将支持的长度、角度单位转换为 SI 数值。
- 对缺失、非法或不合理的输入返回明确的错误信息。

**实际演示**

例如，输入一个长度为 8 mm 的参数，另一个参数等于该长度的一半，同时输入一个90°角度。

程序能够计算：

| 输入 | 处理后的结果 |
|---|---|
| 8 mm | 0.008 m |
| 8 mm 的一半 | 0.004 m |
| 90° | π/2 rad |

如果参数引用了不存在的变量，或者出现不被允许的表达式，程序会拒绝计算并报告错误。

**工程价值：** 将潜在问题尽量拦截在计算开始之前，减少错误输入进入后续计算流程的风险。

本模块是针对明确支持的数值单位和表达式的校验工具，不是完整量纲分析系统或经过安全认证的表达式沙箱。

### M2：复电磁场数值分析

**解决的问题：如何正确计算复场物理量，并判断数值操作是否可靠？**

电磁场仿真结果通常包含复数形式的电场和磁场。

例如：

$$
\mathbf E=\mathbf E_r+i\mathbf E_i
$$

复数不仅包含幅值，还包含相位。如果直接把复场当作普通实数数组处理，可能丢失重要信息。

本模块使用 NumPy 实现三类核心计算。

**① Poynting 功率通量**

通过电场和磁场计算平均能流密度：

$$
\mathbf S=\frac12\operatorname{Re}
(\mathbf E\times\mathbf H^*)
$$

程序进一步沿指定轮廓计算有符号的功率通量。

数值处理中保留正负符号，并通过反转法向、反转磁场等测试，检查计算是否符合预期的数学性质。

**② Fourier 角向分解**

将角向分布函数分解为不同阶次的 Fourier 分量，用于分析数据中的角向变化特征。

模块支持带权积分，并使用具有已知系数的人工函数进行验证。

**③ 复数最小二乘拟合**

对于两组复数数据，寻找使加权误差最小的复系数：

$$
\min_\alpha\sum_i w_i
|y_i-\alpha x_i|^2
$$

同时输出拟合系数、重叠指标和残差等信息。

这可以帮助区分：两组数据的差别主要来自整体复数缩放，还是存在无法被单个复系数解释的形状差异。

这张图通过已知解析系数的人工 Fourier 信号，展示系数计算与有限级数重构过程。

### M3：计算任务与结果追溯

**解决的问题：程序执行结束以后，如何判断任务是否真正成功？**

在科研计算中，程序执行成功与科学结果有效不是同一回事。

例如，一个任务可能正常退出，但其结果未通过应用层面的验证；也可能中途失败，同时留下部分输出文件。

如果缺少记录，后续就难以判断哪些文件可以使用。

本模块使用 Python 标准库实现小型任务执行与追溯流程：

- 使用固定的 dummy worker 模拟计算任务。
- 记录任务退出码和运行日志。
- 使用 SHA256 计算文件摘要，辅助检测文件变化。
- 将任务执行状态与结果验证状态分别记录。
- 使用 JSON 保存结构化运行结果。
- 拒绝覆盖已经存在的输出目录。
- 在任务失败时保留相应记录。

**实际演示**

| 测试场景 | 预期行为 |
|---|---|
| 正常执行 | 保存输出与成功状态 |
| Worker执行失败 | 记录失败退出码并保留日志 |
| Worker成功但验证失败 | 分别记录运行成功和验证失败 |
| 输出目录已存在 | 拒绝覆盖原有文件 |
| 文件发生变化 | SHA256检查发现摘要不一致 |

**工程价值：** 提高计算过程的可追溯性，避免把程序结束、结果存在和结果有效混为一谈。

该模块并非通用任务调度系统，不提供任意命令执行、集群管理或断电恢复能力。

## 4. 运行演示

### 环境

- Windows
- 已实际验证：Python 3.13.1
- 主要依赖：NumPy、Pydantic
- 测试框架：pytest
- 可选绘图：matplotlib

其他Python版本及Linux环境尚未完成同等验收。

### 安装与运行

在项目根目录打开 PowerShell。

```powershell
python -m venv .venv

.\.venv\Scripts\python.exe -m pip install -c requirements-tested.txt ".[test]"

.\.venv\Scripts\python.exe -I -B -m optics_portfolio.mvp_cli parameters --config examples/configs/toy_valid.json --out runs/params

.\.venv\Scripts\python.exe -I -B -m optics_portfolio.mvp_cli fields-demo --out runs/fields

.\.venv\Scripts\python.exe -I -B -m optics_portfolio.mvp_cli task-demo --case success --out runs/task
```

以上三条命令分别运行参数校验、复场算术演示和固定任务追溯。

运行时需要使用新的输出目录，程序不会覆盖已有结果。

### 自动化测试

```powershell
.\.venv\Scripts\python.exe -I -B -m pytest tests -q
```

项目已经完成Windows环境中的独立安装与自动化测试。测试包含正确输入、故意错误输入、数值参考和任务失败等场景。

具体通过数量、实际环境、测试时长与执行记录，请查看：

[测试结果与验收记录](docs/TEST_RESULTS.md)

### 重新生成Fourier演示图

```powershell
.\.venv\Scripts\python.exe -m pip install ".[plots]"

.\.venv\Scripts\python.exe -I -B examples/fourier_visual_demo.py --out runs/fourier-figure
```

需使用未存在的输出目录。

## 6. 与真实光学仿真研究的关系

本工具包的需求来自反谐振空芯光纤数值研究，但已经从原研究工作区中独立出来。

原研究涉及：

- COMSOL二维电磁模态分析。
- 复传播参数及电磁场数据提取。
- 光纤几何变化下的模态响应比较。
- 功率积分、复场分析及数值可靠性检查。

**本仓库并未包含上述真实研究数据或COMSOL求解流程。**

两者的定位不同：

| 项目 | 主要用途 |
|---|---|
| Optical Simulation Toolkit | 验证和展示Python科学计算工具 |
| Hollow-Core Fiber Numerical Study（拟独立展示的真实案例） | 展示实际光学建模、模态计算与物理结果分析 |

真实案例仍需另外核实数据来源、公开授权、数值边界及个人贡献。

`ALGORITHMIC_FIXTURE_NOT_COMSOL`
